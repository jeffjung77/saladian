# BPMS 쉬운장부

소상공인을 위한 원화 수입·지출 전표와 기간별 집계 프로그램입니다.

## 실행 (Windows cmd)

```bat
cd /d C:\venvs\webapp
C:\venvs\mysite\Scripts\python.exe manage.py migrate
C:\venvs\mysite\Scripts\python.exe manage.py runserver
```

브라우저에서 http://127.0.0.1:8000 접속.

## 기능

- 전표 입력 화면은 매출입력·비용입력·기타전표로 나뉩니다. 매출입력은 매출액 계정(5001)과 수입으로, 비용입력은 매출원가·판매비와관리비·영업외비용·법인세비용 계정과 지출로 제한됩니다.
- 기타전표는 차변 5행·대변 5행을 나란히 입력합니다. 각 칸에서 전체 계정과목 마스터와 원화 정수 금액을 선택합니다. 사용하지 않는 칸은 비워두며, 차변과 대변 각각 한 건 이상 및 양쪽 합계 일치를 필수로 검증합니다. 행별 금액은 서로 달라도 됩니다.
- 각 행의 차변·대변은 하나의 공통 라인 적요(선택, 최대 1,000자)를 사용합니다. 전표 전체 적요는 별도로 유지됩니다. 수정 화면, 분개 상세, 거래처 원장에서도 행별 공통 적요를 확인합니다. 적요만 입력한 빈 행은 저장할 수 없습니다. 기존에 차변·대변 적요가 다른 행은 `[차변] ... / [대변] ...`로 합쳐 보존합니다.
- 날짜·거래처·적요는 전표 전체에 공통입니다. 화면에서 합계와 차액을 실시간 표시하고 서버에서도 다시 검증합니다. 전표와 분개는 함께 저장되며 수정 실패 시 기존 전표를 보존합니다. 합계 한도는 99,999,999,999,999원입니다.
- 신규 전표는 입력유형이 저장되고 수정 시 같은 유형의 화면이 열립니다. 기존 단식전표는 변환 없이 보존하며 기존 방식으로 수정합니다.
- 기타전표의 차변·대변은 수입·지출에 중복 합산하지 않습니다. 메인 화면 하단의 차변/대변 계정별 집계와 거래처별 원장의 기타전표 내역에서 조회합니다. 전표 목록의 차변/대변 내역을 펼치면 분개를 확인할 수 있습니다.

- 제공된 계정과목표를 마스터로 자동 등록하며 전표 신규 입력·수정은 마스터 선택만 허용합니다. `/accounts/`에서 코드를 포함한 전체 표를 조회할 수 있습니다.
- 표에 없는 기존 자유입력 계정과목은 보존하고 `기존 과목 · 재선택 필요`로 표시합니다. 기존 전표 수정 시 등록 과목을 선택해야 저장됩니다. 명칭이 정확히 일치하는 단일 계정만 자동 연결합니다.

- 전표 입력·수정·삭제 (삭제 전 확인)
- 일자, 수입/지출, 계정과목, 거래처, 원화 정수 금액, 적요
- 시작일/종료일로 조회 (양 끝 날짜 포함)
- 수입 합계, 지출 합계, 차액, 계정과목별 합계
- SQLite 영구 저장: db.sqlite3
- 거래처별 원장: `/partners/ledger/`에서 거래처와 기간을 선택해 날짜순 거래 내역, 수입·지출 합계, 기초·기말 누계를 조회합니다. 거래처 미입력 전표도 선택할 수 있습니다.
- 거래처 누계는 수입에서 지출을 뺀 금액이며 외상 미수금·미지급금 잔액은 아닙니다. 거래처명은 전표에 입력된 이름이 정확히 같은 경우 같은 거래처로 처리합니다.

## 재무제표 조회

- 계정별원장: `/accounts/ledger/`에서 계정과목과 기간을 선택합니다. 시작일 이전 기초잔액, 기간 차변·대변 합계, 날짜순 거래 내역, 거래별 잔액과 기말잔액을 조회하고 인쇄할 수 있습니다. 잔액은 차변−대변 기준으로 계산하고 차변/대변 방향과 절댓값으로 표시합니다. 손익대체 전표를 포함하며, 분개와 단식전표의 반영 검증은 재무제표와 동일합니다. 복합전표는 라인 적요를 우선 표시하고, 정보가 부족한 전표는 시작일 이전분까지 미반영 안내합니다.

- 대차대조표(재무상태표): `/reports/balance-sheet/`에서 기준일을 선택합니다. 기준일까지 입력된 반영 가능 전표를 모두 누적해 자산·부채·자본을 표시합니다. 차감계정은 음수로 표시하며, 수익·비용의 미결산 잔액은 자본의 미결산 누적손익으로 반영합니다. 대차 차액도 확인할 수 있습니다.
- 손익계산서: `/reports/income-statement/`에서 시작일·종료일(양 끝 포함)을 선택합니다. 매출액, 매출원가, 판매비와관리비, 영업외수익·비용, 법인세비용과 매출총이익·영업이익·세전이익·당기순이익을 표시합니다. 기본 기간은 올해 1월 1일부터 오늘까지입니다.
- 매출·비용 전표는 상대계정을 필수로 선택합니다. 수입은 상대계정 차변/계정과목 대변, 지출은 계정과목 차변/상대계정 대변으로 계산합니다. 기타전표는 저장된 분개를 그대로 사용합니다. 원금 차입·상환과 자산 취득은 손익계산서에서 비용·수익으로 처리하지 않습니다.
- 기존 전표의 계정과목·상대계정은 추측하지 않습니다. 빠진 정보가 있는 전표는 보고서에 미반영 사유와 수정 링크를 표시하며, 이때 보고서는 잠정 집계입니다. 기존 단식전표를 수정해 실제 상대계정을 선택하면 보고서에 반영됩니다.
- 기초 잔액은 실제 자산·부채·자본에 맞게 기타전표로 입력해야 합니다. 감가상각, 재고 조정, 세금 등은 자동 계산하지 않으며 필요한 분개를 입력해야 합니다. 계정과목표의 원문 분류를 따릅니다.
- 기타전표에서 `손익대체 결산전표`를 선택하면 손익계산서에서만 제외합니다. 이 표시는 수익·비용을 이익잉여금으로 대체하는 전표에만 사용하며, 일반 결산 조정(감가상각 등)에는 선택하지 않습니다. 대차대조표는 대체 전표까지 포함한 잔액을 사용하므로 대체한 손익을 자본에 다시 합산하지 않습니다.
- 두 보고서에서 인쇄를 지원합니다. 입력 장부를 바탕으로 한 관리용 보고서이며 법정 재무제표 자동 작성·신고 기능은 아닙니다. 기준일 재무상태와 기간 손익을 구분하는 구성은 [IFRS Foundation IAS 1 소개](https://www.ifrs.org/issued-standards/list-of-standards/ias-1-presentation-of-financial-statements.html/)를 참고했습니다. IFRS 준수를 표방하지 않습니다.

로그인 없는 로컬 단일 사용자 MVP입니다. 기타전표의 차변·대변 입력과 장부 기준 재무제표 조회를 지원하며, 자동 결산·세무 신고·부가세 자동 분리·다중 사업장 기능은 포함하지 않습니다. 외부 공개 전에는 인증과 운영 보안 설정이 필요합니다.
