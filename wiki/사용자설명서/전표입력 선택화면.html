전표입력 선택화면

사용자 설명서 · 버전: 알파 1.0 · 2026년 10월 30일 개발 화면 기준

1. 이 화면에서 하는 일

장부에 기록할 거래에 맞는 전표 종류를 선택하는 시작 화면입니다. 이 화면에서 생성 버튼을 누르면 해당 입력 화면으로 이동합니다. 버튼을 누르는 것만으로 전표가 저장되지는 않습니다.

접근 방법: 로그인 후 상단 메뉴의 전표입력을 선택합니다. 현재 선택된 메뉴는 짙은 초록색으로 표시됩니다.

2. 화면 구성

① 매출입력 ⓘ매출전표 생성
② 비용입력 ⓘ비용전표 생성
③ 일반전표 ⓘ일반전표 생성
④ 국세청 자료 전표화 ⓘ준비 중
⑤ 영수증사진 비용처리 ⓘ사진으로 비용입력하기

기능 위치를 설명하기 위한 구성도입니다. 기기와 화면크기에 따라 실제 배치가 달라질 수 있습니다.

선택 항목언제 사용하나요?
① 매출전표 생성상품 판매·용역 제공 등의 매출을 기록할 때 선택합니다. 매출 거래의 공급가액과 필요한 부가세 정보를 입력하는 화면으로 이동합니다.
② 비용전표 생성사업 운영에 필요한 비용을 직접 입력할 때 선택합니다. 비용 계정과 상대계정, 공급가액과 필요한 부가세 정보를 입력합니다.
③ 일반전표 생성차변·대변 계정과 금액을 직접 지정해 분개할 때 선택합니다. 예금 간 이체 등 단순 매출·비용 입력으로 처리하기 어려운 거래에 활용합니다. 차변·대변 합계가 일치해야 저장됩니다.
④ 국세청 자료 전표화현재 ‘준비 중’인 기능입니다. 이 선택화면에서는 국세청 자료를 가져오거나 전표를 생성할 수 없습니다.
⑤ 사진으로 비용입력하기촬영하거나 보관 중인 영수증 사진으로 비용전표를 작성할 때 선택합니다. 사진 선택·업로드와 분석 결과 확인을 거쳐 비용전표를 생성합니다.

3. 전표 종류 선택부터 저장까지

  1. 거래 종류를 확인합니다.
    매출은 매출입력, 비용은 비용입력, 직접 분개가 필요한 거래는 일반전표를 선택합니다.
  2. 해당 생성 버튼을 누릅니다.
    ‘매출전표 생성’, ‘비용전표 생성’, ‘일반전표 생성’ 중 원하는 버튼을 클릭합니다.
  3. 이동한 화면에서 거래 내용을 입력합니다.
    전표일자, 거래처, 계정과목·상대계정, 금액과 적요 등을 입력합니다. 일반전표는 차변·대변을 각각 입력합니다. * 표시는 필수 입력 항목입니다.
  4. 내용을 확인하고 전표 저장을 누릅니다.
    저장 완료 안내와 전표번호를 확인합니다. ‘전표 확인하기’는 전표집계로, ‘계속 입력하기’는 새 입력 화면으로 이동합니다.
중복 기록에 주의하세요.
같은 거래를 수동 비용입력과 영수증사진 비용처리 양쪽에서 각각 등록하면 별도 전표로 기록될 수 있습니다. 이미 입력한 거래인지 먼저 확인하세요.

4. info아이콘 이용 방법

각 섹션 제목 오른쪽의 ⓘ info아이콘에 마우스를 올리면 기능 설명이 표시됩니다. 모바일에서는 아이콘을 누르세요. 다시 누르거나 다른 부분을 누르면 설명을 닫을 수 있습니다.

항목아이콘의 설명
매출입력매출 거래와 공급가액·부가세를 입력합니다.
비용입력비용 거래와 공급가액·부가세를 입력합니다.
일반전표차변·대변 계정과 금액을 직접 입력합니다.
국세청 자료 전표화국세청 자료를 바탕으로 전표를 생성합니다. 현재는 준비 중입니다.
영수증사진 비용처리촬영한 영수증 사진을 바탕으로 비용전표를 생성합니다.

5. 사용 시 참고사항

화면크기: 상단 오른쪽 ‘화면크기’의 − / + 버튼으로 프로그램 표시 배율을 조절합니다. 모바일에서는 선택 항목이 세로로 배치될 수 있습니다.

영수증 분석: Google Vision을 이용한 분석은 인터넷 연결과 서비스 설정이 필요합니다. 분석값을 원본과 대조한 뒤 전표를 생성하세요.

저장 한도: 사용자별 전표 생성 한도가 설정되어 있으면 저장이 제한될 수 있습니다. 한도 안내가 나타나면 시스템관리자에게 문의하세요.

자동 로그아웃: 마지막 활동 후 30분 동안 아무 동작이 없으면 자동 로그아웃됩니다. 전표 작성 후 저장 결과를 확인하세요.
