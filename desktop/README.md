# BPMS 쉬운장부 개인 PC용

Windows 10/11 x64용입니다. Python을 별도로 설치하지 않아도 됩니다.

1. `EasybookSetup.exe`를 실행하고 설치하기를 누릅니다.
2. 바탕화면의 **BPMS 쉬운장부** 아이콘을 클릭합니다.
3. 브라우저에서 업체명·아이디·비밀번호를 최초 1회 등록합니다.
4. 매출·비용·기타전표 입력, 장부·보고서 조회, 인쇄·Excel 출력, 영수증 사진 보관을 사용합니다.
5. 종료할 때 실행창의 **프로그램 종료**를 누릅니다. 브라우저 탭을 닫는 것만으로 프로그램이 종료되지는 않습니다.

## 자료 보관

장부는 `%LOCALAPPDATA%\BPMS\EasybookData\easybook.sqlite3`, 사진은 같은 폴더의 `receipts`에 저장합니다.
프로그램 설치 폴더와 자료 폴더는 분리되어 있습니다. **프로그램 종료 후 자료 폴더 전체를 별도로 복사하여 백업**하세요.
기존 자료를 유지한 채 업데이트하려면 프로그램을 종료하고 같은 설치 폴더에 새 버전을 설치하세요.
다른 PC와 자동 동기화하거나 기존 클라우드 장부를 가져오는 기능은 포함하지 않습니다.
동일 Windows 계정 아래에 하나의 로컬 장부 계정을 만드는 개인용입니다.

## Google Vision 사용 (선택)

수동 입력·보고서·사진 보관은 인터넷 없이 사용할 수 있습니다. 사진을 자동 인식하려면:

1. 본인 Google Cloud 프로젝트에서 Cloud Vision API와 결제를 활성화합니다.
2. 해당 API를 사용할 수 있는 본인의 서비스 계정 JSON 인증파일을 준비합니다.
3. 쉬운장부 실행창의 **Google Vision 설정**에서 인증파일을 선택합니다.
4. 브라우저의 영수증 보관 내역에서 **영수증 분석**을 누릅니다.

분석할 때만 영수증 사진이 Google로 전송됩니다. 인터넷 연결이 필요하며 Google 이용료가 별도로 발생할 수 있습니다.
인증파일은 자료 폴더의 `google-vision.json`으로 복사됩니다. 이를 다른 사람에게 제공하지 마세요.
등록 설정을 해제하려면 프로그램을 종료하고 이 파일을 삭제하세요. 패키지에는 개발자 인증정보를 포함하지 않습니다.

## 제거

쉬운장부를 종료한 뒤 설치 폴더와 바탕화면·시작 메뉴 바로가기를 삭제합니다.
자료 폴더는 자동 삭제하지 않으며, 자료 삭제가 필요하면 백업 후 별도로 삭제하세요.

## 배포 관련

Windows용 디지털 서명 인증서로 서명하지 않은 내부 시험 배포본입니다. Windows에서 게시자 확인 경고가 표시될 수 있습니다.
관리자 권한과 외부 포트 개방은 필요하지 않으며 서버는 127.0.0.1에만 연결됩니다.
가입·구독·게시판·시스템관리·국세청 연동은 개인 PC용에서 제공하지 않습니다.

## 개발자 빌드

`python -m pip install -r desktop/requirements-build.txt` 후 `python desktop/build.py`를 실행합니다.
빌드 결과는 `dist/release/EasybookSetup.exe`와 `Easybook-Personal-Windows-x64.zip`입니다.
실제 개발 DB, 첨부파일, .env, 인증키는 입력으로 사용하지 않습니다.
